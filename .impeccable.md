## Design Context

**Target audience**: University admissions committee for inVision U (a new tech university in Kazakhstan). Admins review candidate applications, scout talented students from olympiad results, and manage the pipeline.

**Use cases**:
- Review and score incoming student applications
- Scout talented students from international olympiads (IMO, IOI, IPhO, IChO, IZhO)
- Enrich candidate profiles with AI analysis
- Track candidate pipeline (discovered > contacted > applied > admitted)
- Configure system settings (AI model, API keys)

**Brand personality/tone**: Professional yet modern. Confident, data-driven, forward-thinking. This is a tool for people making important decisions about young talent. It should feel authoritative but approachable — like a premium SaaS dashboard, not a toy.

**Color direction**: Warm orange (#F97316) as primary accent (already established). Clean light backgrounds. Avoid generic gray-everything.

**Typography**: Clean, modern, readable. This is a data-heavy admin tool — clarity over decoration.

**Framework**: React 18 + TypeScript + Tailwind CSS (single-file App.tsx SPA)
